# Capoeira Eventos

Aplicação Angular para gerenciamento de eventos de capoeira.

## Requisitos

- Node.js 20+
- npm 10+

## Instalação

```bash
npm install
```

## Execução local

```bash
npm start
```

A aplicação ficará disponível em `http://localhost:4200/`.

## Scripts úteis

- `npm start`: inicia o servidor de desenvolvimento
- `npm run build`: gera build de produção
- `npm test`: executa os testes
- `npm run test:ci`: executa testes em modo CI (headless)

## Stack

- Angular 21
- Firebase / AngularFire
